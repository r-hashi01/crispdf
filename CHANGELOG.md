# Changelog

## 0.1.0

Initial public package for `@vellum/core`.

- Browser-only DOM to PDF hybrid renderer.
- Raster background with selectable PDF text overlay.
- Multi-page output.
- Standard PDF font fallback.
- Google Fonts discovery and WOFF2-to-SFNT decoding.
- CID-keyed web-font embedding with `/ToUnicode` maps.
- RTL shaping/placement support for Arabic-like runs.
